# AI TEACHER — HOW TO USE

STEP 1 — OPEN THE APP

Open:

AI Teacher – Personal Exam Tutor

You will see the Home screen.

---

STEP 2 — SELECT TEACHING LANGUAGE

Choose:

English

or

Telugu

or

Telugu + English

For example:

Select:

Telugu + English

The teacher will explain the lesson in natural Telugu + English.

---

STEP 3 — LEARN USING ONLY A TOPIC NAME

From Home select:

Teach a Topic

Enter:

Python

Press:

Start Teaching

The teacher prepares the lesson.

You can see the explanation.

You can hear the explanation.

---

STEP 4 — TEACH FROM YOUR OWN NOTES

Select:

Teach My Material

Paste your study material.

Example:

Python is a high-level programming language...

Topic name is OPTIONAL.

You may enter:

Python

or leave it empty.

Press:

Start Teaching

The application understands the material and creates a lesson.

---

STEP 5 — VIEW THE LESSON

The screen shows:

Teacher Explanation

Core Concept

Example

Important Point

Exam Point

Quick Revision

The current section is highlighted with high-contrast text.

---

STEP 6 — LISTEN TO THE TEACHER

When speaking is available:

🔊 Teacher is speaking...

You can use:

Pause

Resume

Stop

If there is no sound:

Go to:

Settings
→ Diagnostics
→ Test Voice

---

STEP 7 — USE BLUETOOTH EARBUDS

1. Connect Bluetooth earbuds to the phone.
2. Turn up media volume.
3. Open AI Teacher.
4. Start a lesson.
5. Start speaking.

Voice should come through the earbuds.

If not:

Settings
→ Diagnostics
→ Test Voice

Then check Android Bluetooth/audio output.

---

STEP 8 — ASK A DOUBT

While the teacher is teaching:

Press:

Ask Doubt

You can type:

"What is a variable?"

OR use the microphone.

---

STEP 9 — SPEAK YOUR DOUBT

Press microphone.

Wait for:

Listening...

Speak clearly.

Example:

"What is a parameter?"

The app converts your speech into text.

---

STEP 10 — TEACHER ANSWERS

The teacher uses the current lesson context.

For Telugu + English:

the answer is shown and spoken in Telugu + English.

---

STEP 11 — CONTINUE THE LESSON

After the answer:

Press:

Continue Lesson

The teacher returns to the previous lesson.

The lesson should continue from where it stopped.

It should NOT restart the whole topic.

---

STEP 12 — ASK MULTIPLE DOUBTS

You can repeat:

Teach
→ Ask Doubt
→ Answer
→ Continue

as many times as needed.

---

STEP 13 — LOCAL AI MODEL

For advanced arbitrary-topic teaching:

Settings
→ AI & Voice Models
→ Local AI

Import a supported quantized GGUF model.

The model is stored locally.

You do not need to import a model for basic application functionality.

---

STEP 14 — SPEECH RECOGNITION MODEL

For reliable offline voice doubts:

Settings
→ AI & Voice Models
→ Speech Recognition

Check whether a supported offline speech model is installed.

If not available:

you can still type your doubt.

---

STEP 15 — CHECK VOICE

Go to:

Settings
→ Diagnostics
→ Test Voice

The phone should say:

"Hello. This is your AI Teacher."

Test English and Telugu separately.

---

STEP 16 — CHECK MICROPHONE

Go to:

Settings
→ Diagnostics
→ Test Microphone

Press Start Test.

Say:

"Hello teacher."

The recognized text should appear.

---

STEP 17 — IF MICROPHONE PERMISSION IS DENIED

Go to:

Android Settings
→ Apps
→ AI Teacher
→ Permissions
→ Microphone
→ Allow

Return to the app.

---

STEP 18 — IF TELUGU VOICE IS NOT AVAILABLE

Go to Android:

Settings
→ Text-to-Speech Output

Check installed speech engines and voices.

Install/select a Telugu voice if available.

Return to AI Teacher.

---

STEP 19 — OFFLINE USE

With local content/model and local voice support:

the application can work without internet.

Cloud AI is optional.

---

STEP 20 — IMPORTANT

There are three separate technologies:

Text-to-Speech:
Teacher text → Teacher voice

Speech-to-Text:
Student voice → Student doubt text

Local AI:
Material/topic → Teacher explanation and answers

Installing one does NOT automatically install the others.

---

## END OF USER GUIDE
